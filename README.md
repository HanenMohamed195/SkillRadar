
# SkillRadar

SkillRadar is a Job Intelligence platform that collects job opportunities from multiple sources and matches them with users' skills.

## Main Features
- Job Scraping
- Data Engineering ETL Pipeline
- Bronze, Silver and Gold Architecture
- CV Skill Extraction
- Job Matching System
- Telegram Notifications
- Power BI Dashboard

## Technologies
- Python
- Databricks
- SQL
- Supabase
- Streamlit
- Power BI
